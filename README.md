1. 위 링크를 누르면 내려받기 화면이 열립니다. 로그인하지 않아도 됩니다.
2. 화면 아래 **Assets**에서 `vibecoding-mfg-student-v1.2.zip`을 누릅니다.

### 이용 전에 알아 둘 것

- 모든 회사 이름, 품번, 사람, 수치는 이 책을 위해 새로 만든 **가상 데이터**입니다. 실제 회사의 자료가 아닙니다.
- 폴더마다 `README.md`가 있습니다. 먼저 이 파일을 읽고, 이어서 `예제_프롬프트.md`(AI에게 시킬 말)를 엽니다.
- `정답` 또는 `정답지` 폴더는 내가 만든 결과와 대조하는 데 씁니다.
- 회사의 실제 자료로 연습할 때는 회사 정책을 먼저 확인하세요. 책의 부록 B 보안 체크리스트를 함께 보면 됩니다.
- 받은 파일이 손상되지 않았는지 확인하려면, 압축을 푼 폴더의 `파일목록.csv`에 적힌 파일별 SHA-256 값과 비교합니다.

## 폴더 구성

| 부 | 폴더 | 책의 절 |
|---|---|---|
| 1부 시작하기 | `2장_과제고르기` | 2장 내 업무에서 자동화할 일 고르기 |
| | `3장_첫예제` | 3장 바이브코딩 개발 환경 만들기(첫 실습) |
| 2부 업무별 개발 | `4-1_측정리포트` | 4-1 측정 리포트(PDF) 값을 검사성적서(엑셀)에 자동으로 채우기 |
| | `4-2_한글양식` | 4-2 한글(HWPX) 양식의 정해진 칸 자동으로 채우기 |
| | `4-3_불량보고` | 4-3 현장 입력·사진으로 불량보고서(엑셀) 쓰기 |
| | `4-C_세방식비교` | 4-C 같은 성적서를 세 가지 방식으로 만들어 보기 |
| | `5-1_치수검사` | 5-1 치수검사기록서에서 공차 이탈과 경계값 찾기 |
| | `5-2_조립도BOM` | 5-2 기계 조립도와 자재명세서(BOM) 대조 검증 |
| | `5-C_성적서점검` | 5-C 완성된 성적서 최종 점검하기 |
| | `6-1_월품질현황` | 6-1 기초자료 5종으로 월 품질현황 보고서 만들기 |
| | `6-2_라인현황` | 6-2 라인별 검사 데이터 집계와 이상 알림(현황판) 만들기 |
| | `6-C_근태집계` | 6-C 근태 집계와 주간 근무시간 한도 관리 |
| | `7-1_구매관리` | 7-1 구매 요청부터 월 마감까지 한 번 입력으로 처리하기 |
| | `7-2_생산계획` | 7-2 생산계획 자동 편성과 결품 점검 |
| | `8-1_작업일보` | 8-1 휴대폰으로 입력하는 다국어 작업일보·자주검사 |
| | `8-C_읽기전용현황판` | 8-C 기존 시스템 데이터를 읽어 공정 현황판 만들기 |
| 3부 현장에 넘기기 | `9장_저장소운영` | 9장 팀으로 함께 개발하기: 부서별 저장소 운영 |
| | `10장_인계묶음` | 10장 오래 쓰는 도구로 만들기: 문서화·유지보수·인계 |
| | `10-C_설명서자동만들기` | 10-C 사용 설명서를 자동으로 만들기 |

1장(업무 자동화 지도)은 따로 실습 자료가 없습니다.

`10-C_설명서자동만들기\실행용`에는 10-C에서 화면을 찍을 때 쓰는 **샘플 앱**(작업일보 앱의 실행용 사본)이 들어 있습니다. 8-1절에서 직접 만드는 프로그램을 대신하지 않으니, 8-1은 책의 절차대로 먼저 만들어 보세요.
